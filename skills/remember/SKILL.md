Use the creation fields and scope rules in [the global memory rule](../../rules/memory.md).

1. Preserve the user's meaning, reason, and limits. Resolve whether it applies globally or to one project.
2. Submit without duplicate searches. Explain corrections and link old claims when already known.
3. Save durable knowledge as a complete observation with `Status = New`. For a TODO or handoff, read the latest contents before updating the relevant slot. Save both when each serves a useful purpose.
4. Confirm the write and link the saved page. Report what was recorded.

Do not turn a suggestion into an accepted decision. Change repository instructions only when the user asks for that too.
