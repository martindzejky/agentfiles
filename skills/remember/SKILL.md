Use the creation fields and scope rules in [the global memory rule](../../rules/memory.md).

1. Preserve meaning, reason, and limits. Resolve Global or Project scope.
2. Submit without duplicate searches. Explain corrections and link old claims when already known.
3. Save durable knowledge as an observation with `Status = New`. For TODOs or handoffs, read and update the relevant slot. Use both when useful.
4. Confirm the write and link the saved page. Report what was recorded.

Preserve suggestions as suggestions. Change repository instructions only when requested.
