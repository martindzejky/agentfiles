# Anti-AI-slop

These are the defaults models reach for when **not reading the room** — the patterns that make an artifact look generated rather than designed.

**Every item here is contextual.** Avoid them _unless the brief, brand, or project docs explicitly call for them_. Intentional purple, bold serif, maximalist motion, or a centered manifesto hero are all valid creative choices when justified. These rules target unthinking defaults, not deliberate risk.

When you lack a real value, leave an honest placeholder (`—`, a grey block, a labelled stub) rather than inventing one.

## Color & atmosphere

- Aggressive purple/violet gradient backgrounds; a gradient on every section
- Purple-gradient hero on a dark mesh
- Cliched purple gradients on white backgrounds
- Warm beige / cream / peach / pink / orange-brown "AI canvas" backgrounds unless the brand or a provided reference explicitly calls for it
- Oversaturated accents; neon-for-its-own-sake
- Gradient text on huge headlines; gradient stroke as a default flourish

## Typography

- Inter / Roboto / Arial / system fonts as a _display_ face (body is fine)
- Reaching for the same "designer default" display face every time (e.g. Space Grotesk) — vary faces across artifacts instead of converging
- A random second font family to emphasize one word — emphasize within a headline using italic or bold of the **same** family

## Layout & composition

- Three equal feature cards in a row as the reflexive section layout
- Predictable, cookie-cutter layouts and component patterns
- Rounded card with a left colored-border accent
- Decorative crosshair grids and hairlines with no organizing job
- Eyebrow / small-caps label above every headline; section numbers as eyebrows (`06 · How it works`)
- Third consecutive zigzag image/text row; duplicate section templates on one page
- Split-header with a giant headline left and a tiny floating explainer right with no compositional purpose
- Custom mouse cursors
- Progress bars with fat tracks for simple comparisons on marketing pages
- Pills and tags overlaid on photos; photo-credit captions on stock placeholders

## Imagery & chrome

- Hand-drawn SVG humans / faces / scenery
- Fake product UI built from boxes (box-drawn dashboards, terminals, task lists) pretending to be a real preview
- Designer/demo chrome leaking into product UI — viewport toggles, settings panels, target-count badges; ship real product UI, not a mockup board
- Generic emoji feature icons (✨ 🚀 🎯) or an icon next to every heading
- Version badges in the hero (`BETA`, `v0.6`) unless the brief is a launch
- Scroll cues (`Scroll to explore`); locale/weather/time strips in nav or footer
- Decoration strips (`DESIGN · BUILD · SHIP`) with no navigational purpose

## Content & copy signatures

- Filler copy — "Feature One / Feature Two", lorem ipsum
- Generic names and brands (Jane Doe, Acme, Nexus, SmartFlow)
- Invented metrics and fake-precise stats (`10× faster`, `99.9% uptime`, `92%`, `4.1×`, `5.8 mm`) with no real source
- Filler verbs (Elevate, Seamless, Unleash, Revolutionize)
- Performative labels ("Field notes", "Quietly in use at", "From the bench")
- Em-dash as a stylistic crutch throughout visible copy
