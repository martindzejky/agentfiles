## What is retained

The detailed motion-design reference library preserves the author's processes, opinionated starting defaults, design systems, timing/curve tables, worked native graphs, code examples, specialist craft, review tests, and failure lessons. This includes the split design-first, animation-principles, ui-mastery, build-orchestration, depth-space, and liquid-glass modules; construction/type/effects/rigs/galleries; character, rigging, board, and collage packs; reference analysis, transitions, localization, collection, and handoff guidance.

The separate Fusion reference's realities and setting-format modules preserve technical pitfalls and serialization knowledge. The full manual distillations and harvested API/input/registry data are not vendored: use current native documentation and live input discovery. [TSV], [corpus], [manual], [live], and [unverified] retain their upstream meanings, not a claim that their underlying data or tests run here.

## What is adapted

- [Native execution](native-execution.md) replaces the upstream multi-server routing/technical execution contract. Ordinary graph edits use the existing native Resolve MCP. Filesystem access follows the existing Resolve skill's sandbox guidance.
- [Graph style](graph-style.md) retains readable layout conventions without a custom layout operation or connector-specific ban on Groups.
- [Performance](performance.md) retains freeze/cache tradeoffs, invalidation, render-cost lessons, and benchmark context without cache operations, automatic fingerprinting, or server guarantees.
- Visual foundation keeps concepts, style frames, direction review, storyboarding, beat maps, sound planning, and quality checks. Fusion handles motion previews; HTML stills are optional planning aids. No browser renderer or external animatic pipeline is required.
- Media packaging keeps shot specifications, actual-file checks, fitting, timing, replacement, and editable overlays. The upstream author's image/video models, music provider, machine-specific fonts, and generation workflow are not user preferences here. External generation is optional only when separately requested.
- Connector-only scene-authoring schemas, installation, runtime helpers/components, agent definitions, and recovery protocols are not included. Their useful planning, construction, layout, and review ideas remain in native form. Links to upstream code provide provenance, not an instruction to install it.

The reference library is deliberately detailed. Local part indexes and the skill router keep it available without loading it all. Keep numerical examples, special cases, and failure explanations when updating; do not replace them with generic design advice. Differences between modules are resolved by the actual brief/reference and the execution contract, not by inventing a universal house style.
