# .agentfiles

My personal AI agent configuration files (skills, rules, commands, agents). So my AI assistants always feel at home...

## Installation

Almost everything is automated thanks to a bunch of scripts and [dotbot](https://github.com/anishathalye/dotbot).
Just clone this repository and run the install script:

```
git clone https://github.com/martindzejky/agentfiles ~/.agentfiles
cd ~/.agentfiles
./install
```

## Sources

Most of the files in this repo come from my own work and experience. Some files like skills or rules were adapted from other repositories, and then I tweaked them to fit my own needs.
